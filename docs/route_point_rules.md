# 路线点位规则

日期：2026-09-08。

## 本次生效的功能

1. 连接桥端点位于所属区域内部时，程序不再把“最近垂足”当作桥口。程序沿连接桥记录折线的真实方向向外寻找，与区域边界第一次相交的位置就是桥口；桥口以内的桥点不生成执行任务。
2. 连接桥端点位于区域外部或边界上时，不延长桥线猜测交点，继续使用原来的边界接入算法。
3. 全部区域、桥和清扫线拼成最终任务链后，任意相邻执行点距离不超过15cm时统一合并，不再按区域点、桥点、清扫点或显式停车标记豁免。
4. 路线起点和最终目标保持不变；中间近点优先保留真实桥口/桥点，否则选择使前后局部路线变化较小的坐标。
5. 近点合并后统一更新前后任务的x/y、经纬度、航向、长度、连续折线序号、转向角和停车标记，再执行连续性与回原点校验。

所有修改都只作用于规划副本，原始区域记录点和连接桥记录点不删除。

## 桥口判断

- “在区域内部”要求桥端点确实位于多边形内部，并且距边界超过0.1cm。0.1cm以内只视为预览三位小数取整造成的数值误差。
- 多点或L形连接桥从所属区域一侧开始，程序沿每一段依次检查。只有从内部真正穿到外部的第一个交点才是桥口；仅与凹边界相切但仍留在区域内的点不是桥口。
- 如果桥折线一直没有离开区域，说明没有可信交点，回退到原接入算法，不凭空补一条桥。
- 反向通行使用同一套计算，因此同一座桥往返使用同一个几何桥口。

## 15cm合并

任务段 `P -> Q` 的整数厘米距离不超过15cm时，该任务不再单独输出：

- 第一段短任务保留整条路线起点P，下一任务从P直接开始。
- 最后一段短任务保留整条路线终点Q，上一任务直接到Q。
- 中间短任务若P/Q只有一端是真实桥口或桥点，优先保留该端。
- 其他中间短任务分别计算保留P和保留Q后的前后局部长度，选择总长度更小的一端；相同时稳定保留P，保证Python 2/3结果一致。
- 合并后重新检查新形成的相邻任务，但不会用“A距B近、B距C近”推导“A距C也近”；只有最终实际任务段本身仍不超过15cm时才继续合并。

这条规则替代原来“小于3cm普通转场才删除”的收尾规则。旧的5cm浮点去重、30cm边界首尾闭合、55度停车转向仍解决不同问题，不等于15cm执行点合并。

## hhh123实数验证

使用备份模型 `4ac2067e3d97.json`、区域顺序 `[2,1]`：

- 区域1侧桥点L1 `(14.526,73.155)` 位于区域内，沿L1到L2方向得到真实桥口约 `(16.164,99.429)`，整数执行坐标为 `(16,99)`；L1不再成为执行目标。
- 真实桥口与A2相距约6.34cm，最终只保留真实桥口，不生成A2到桥口的短任务。
- 区域2侧L2 `(26.025,257.550)` 位于区域外，保留原接入方法；其11.46cm投影短段由15cm规则吸收。
- 返回原点版本由23段降为18段，8条业务清扫线不变，总长5849cm，最终仍回到原点。
- 不返回原点版本为16段、7条业务清扫线、总长4917cm。
- 两个版本都没有不超过15cm的独立任务，原始模型内容未被修改。

